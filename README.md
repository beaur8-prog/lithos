# Lithos

macOS용 로컬 Markdown 지식 관리 앱. 설치된 Obsidian 1.14.4의 화면과 동작을 관찰하고, Markdown·JSON Canvas의 공개 규격을 바탕으로 독립적으로 구현했습니다. 원본 앱의 코드나 자산을 앱에 포함하지 않습니다.

기능별 사용법은 [Lithos 사용 설명서](Lithos_USER_GUIDE.md)를 참고하세요.

## 실행

macOS에서 Node.js와 npm을 설치한 뒤 다음 명령으로 소스에서 실행합니다.

```sh
npm ci
npm run build
npm start
```

개발 중에는 터미널 두 개에서 `npm run dev`, `npm run desktop`을 실행합니다. 패키징은 `npm run package`입니다. 파일 동기화 메타데이터가 서명을 방해하지 않도록 앱은 `~/Library/Caches/LithosBuild/mac-arm64/Lithos.app`에서 빌드·서명하고, 프로젝트의 `release/`에는 ZIP으로 저장합니다.

생성된 `release/Lithos-mac-arm64.zip`을 풀고 `Lithos.app`을 `/Applications`로 옮겨 실행합니다. 설치 파일은 Git 저장소에 포함하지 않습니다. Apple Silicon용 로컬 빌드이며 ad-hoc 코드 서명을 사용합니다. Apple Developer ID 배포 서명·공증은 적용하지 않았습니다.

## 구현된 기능

- 실제 로컬 폴더 보관함, 하위 폴더, Markdown 노트 생성·이름 변경·이동
- 자동 저장, 종료 시 저장 완료 대기, 외부 파일 변경 반영
- 실시간 편집, 원본, 읽기, 편집/미리보기 및 두 노트 분할 화면
- Markdown 표·체크리스트·코드 블록·수식·로컬 이미지
- 위키 링크·별칭·제목 링크, 없는 노트 생성, 자동완성, 백링크·나가는 링크
- 이름 변경 시 내부 링크 갱신, 캔버스 파일 참조 갱신
- 전체 검색, 태그, 개요, 북마크, 빠른 전환, 명령 팔레트
- 전체/로컬 연결 그래프, 노드 이동, 검색·필터, 확대·축소
- 일일 노트, 첨부 파일 가져오기, 다크·라이트 테마와 글자 크기
- JSON Canvas: 텍스트·노트 카드, Markdown 미리보기, 이동·크기 조절·색상, 포트 연결·라벨, 다중 선택, 실행 취소/다시 실행, 확대·축소·전체 보기
- 보관함별 작업 공간 복원과 되돌릴 수 있는 휴지통
- Mac에서 직접 제공하는 공유 링크와 4자리 암호를 통한 브라우저 공동 편집, 외부 HTTPS 접속, 모바일 브라우저 보기, 공유본 갱신·만료·중지

## 문서 공유

노트를 열고 오른쪽 위 **노트 공유** → **공유 링크 만들기** → **링크 복사**를 누릅니다. 다른 PC나 휴대폰에서 링크를 열면 설치·로그인 없이 읽을 수 있습니다. 왼쪽 아래 **공유 링크 관리**에서 보관함에 관계없이 모든 공유본을 중지할 수 있습니다.

문서와 이미지의 복사본은 이 Mac의 `~/Library/Application Support/Lithos/shares/`에 저장합니다. 앱의 로컬 HTTP 서버를 Cloudflare Quick Tunnel이 HTTPS로 중계합니다. `cloudflared`가 필요하며, 이 Mac에는 Homebrew로 설치되어 있습니다. 다른 Mac에서는 `brew install cloudflared`로 설치하세요. 라우터 포트 개방이나 계정 없이 사용할 수 있지만, Quick Tunnel은 임시 연결로 서비스 가용성을 보장하지 않습니다.

- Mac과 Lithos가 실행 중이어야 합니다. macOS에서 창만 닫으면 공유는 계속되고, ⌘Q로 앱을 종료하면 중단됩니다. 활성 공유본이 있으면 앱이 자동 잠자기를 방지하지만, 사용자가 직접 잠자기를 선택하거나 네트워크를 끊으면 접근할 수 없습니다.
- 앱 재시작·터널 재연결 후에는 임시 도메인이 바뀔 수 있습니다. 새 주소를 복사해서 전달해야 합니다. 고정 주소에는 별도 도메인과 이름 있는 Cloudflare Tunnel 설정이 필요합니다.
- 본문과 삽입된 로컬 이미지를 포함합니다. **연결된 첨부 파일 다운로드 허용**을 켜면 본문의 파일 링크도 포함합니다. 기존 공유본은 이 옵션이 꺼져 있으므로 선택 후 **공유본 갱신**을 누르세요. 일반 노트 링크, 보관함 전체와 본문의 YAML 속성은 제외합니다. Canvas 문서의 웹 미리보기는 아직 지원하지 않습니다.
- 읽기 전용으로 공유한 노트를 수정한 뒤 **공유본 갱신**을 누르면 같은 링크에 반영됩니다. 원본 삭제·이동과 공유본의 수명은 별개입니다. 삭제한 노트의 공유도 **공유 링크 관리**에서 중지할 수 있습니다.
- 7일·30일·90일·만료 없음 중 선택합니다. 만료·공유 중지 후에는 본문·이미지·다운로드 파일 모두 접근을 거부합니다. 이미 내려받은 복사본은 회수할 수 없습니다.
- 본문 최대 1 MB, 표시용 이미지 한 개 최대 8 MB, 본문과 표시용 이미지 합계 최대 20 MB입니다. 다운로드 파일은 한 개 최대 250 MB, 본문·이미지·다운로드 합계 최대 500 MB입니다. 표, 체크리스트, 코드, 수식을 지원하며 외부 이미지는 HTTPS만 표시합니다.
- 공유 화면에서는 언어를 `mermaid`로 지정한 코드 블록을 자동으로 다이어그램으로 표시합니다. **크게 보기**와 **Mermaid 원문 보기**를 제공하며, 문법이 틀린 블록은 안내와 원문을 표시하고 나머지 문서는 계속 읽을 수 있습니다. Mermaid는 앱에 포함되어 외부 렌더링 서비스로 본문을 보내지 않습니다. 한 블록은 20,000자·연결선 500개까지 지원하며 클릭 명령과 임의 HTML 실행은 비활성화합니다. 데스크톱 편집기의 Mermaid 미리보기는 아직 포함하지 않습니다.

서버는 loopback에만 바인딩합니다. 읽기 전용이 기본이며, 소유자가 공동 편집을 켠 노트에 한해 암호 인증 후 본문 쓰기 API를 제공합니다. 공유 주소에는 192비트 난수 토큰을 사용하고, 요청마다 만료·공유 중지를 검사합니다. 파일 경로 탐색, 디렉터리 목록, 로컬 파일 임의 읽기는 허용하지 않습니다. 공유 응답에는 캐시 방지, 검색 색인 제외, 리퍼러 차단과 Content Security Policy를 적용합니다.

### 브라우저 공동 편집

공유 창에서 해당 링크의 **암호 4자리**에 숫자를 입력하고 **공동 편집 켜기**를 누릅니다. 참여자는 같은 공유 링크에서 **암호 입력하고 편집**을 눌러 이름과 암호를 입력합니다. 읽기에는 암호가 필요하지 않습니다. 기존 링크는 기본적으로 읽기 전용입니다.

- 여러 브라우저의 입력을 CodeMirror의 변경분 병합(OT)으로 반영하고, 약 1초 간격으로 다른 참여자의 내용을 받습니다. 참여자 이름과 저장 상태가 표시되며 마크다운 작성·미리보기·실행 취소를 지원합니다.
- 본문은 Mac 보관함의 원본 `.md`에 자동 저장됩니다. 기존 YAML 속성은 편집 화면에서 제외하고 보존합니다. 공동 편집 설정 때 원본을 비공개 `shares/edit-backups/`에 백업합니다.
- 켜져 있는 노트는 Mac 앱에서 읽기 전용으로 표시됩니다. 소유자도 공유 링크를 열어 함께 작성하세요. 연결된 노트의 갱신 충돌을 막기 위해 공동 편집 중에는 해당 보관함의 파일 이름 변경을 잠시 제한합니다.
- 공동 편집을 끄면 Mac 앱에서 다시 편집할 수 있습니다. 새 로컬 첨부 파일은 편집을 끈 뒤 소유자가 추가하고 **공유본 갱신**으로 승인해야 합니다. 브라우저에서 임의의 로컬 파일 경로를 입력해도 새 파일이 공개되지 않습니다.
- 암호를 바꾸거나 편집을 끄거나 링크가 만료·중지되면 기존 편집 인증도 종료됩니다. 인증은 8시간 동안 유효하며, 네트워크 단절 후에는 자동 재접속합니다. 원본이 다른 앱에서 바뀌면 덮어쓰지 않고 중지합니다. 이 경우 소유자가 원본을 확인한 뒤 공동 편집을 다시 설정하세요.
- 저장 전 입력은 현재 브라우저 탭의 세션 저장소에 보관하고, **현재 내용 내려받기**로 파일로 저장할 수 있습니다. 인증 종료 후 다시 참여할 때 이전 보관본은 별도로 내려받아 비교하세요. 탭을 닫으면 브라우저의 세션 보관본이 사라질 수 있습니다.
- 암호는 솔트와 scrypt 해시로 저장합니다. 링크당 암호 실패 5회 후 1분간 재시도를 제한하며, 편집 요청은 별도 무작위 인증 토큰·출처 검사·본문 크기 제한을 적용합니다. 4자리 암호는 간편한 편집 참여용이므로 링크와 암호는 참여자에게만 전달하세요.

## 데이터

### 파일 다운로드 링크

노트 편집 화면의 **첨부 파일 가져오기**(클립 버튼)로 Mac의 파일을 선택하면 보관함 `attachments/`에 복사합니다. 이미지는 본문에 표시하고, 그 외 파일은 다운로드 링크로 넣습니다. 공유 창에서 **연결된 첨부 파일 다운로드 허용**을 선택한 뒤 공유를 만들거나 갱신하면, 상대방은 파일명 옆의 다운로드 표시를 눌러 저장할 수 있습니다.

기존 파일은 `[자료 받기](attachments/report.pdf)` 같은 Markdown 링크, 참조 링크, `[[attachments/report.pdf]]` 또는 `![[attachments/report.pdf]]`로 연결할 수 있습니다. 파일을 노트 하위 폴더에서 연결할 때는 노트 기준 상대 경로나 `/attachments/report.pdf`처럼 보관함 루트 기준 경로를 사용하세요. 보관함 밖 파일은 클립 버튼으로 가져오세요. `file://` 주소나 Mac의 절대 경로는 외부에 제공하지 않습니다.

일반 `.md`·`.canvas` 노트 링크는 공유하지 않습니다. 해당 파일 자체를 내려받게 하려면 클립 버튼으로 첨부하거나 `[원본 받기](attachments/note.md?download=1)`처럼 명시합니다. 이 경우 YAML 속성을 포함한 원본 파일 전체를 복사하되, 그 안에서 연결하는 다른 파일까지 따라가지는 않습니다.

파일 복사본은 비공개 공유 폴더의 `downloads/`에 별도로 저장하며 큰 파일은 스트리밍으로 제공합니다. 한글 파일명과 이어받기 요청을 지원하고 HTML 등도 브라우저 실행 대신 파일로 내려받습니다. 원본 파일 변경은 다음 공유본 갱신 때 반영됩니다. 다운로드 허용을 끄고 갱신하거나 공유를 중지하면 파일 접근도 중단됩니다.

### 보관함 파일

첫 실행의 예제 보관함은 `~/Lithos Vault`입니다. 기존 Obsidian 보관함은 자동으로 변경하지 않습니다. 원하는 폴더를 **보관함 열기**에서 선택할 수 있습니다.

- `.md` / `.canvas`: 일반 텍스트 파일
- `.lithos/workspace.json`: 탭·설정·북마크
- `.lithos-trash/`: 복원 가능한 삭제 파일
- `attachments/`: 가져온 첨부 파일

파일은 임시 파일로 쓴 후 원자적으로 교체합니다. 보관함 밖 경로와 내부 심볼릭 링크를 거부합니다. 렌더러는 Node API에 직접 접근하지 않습니다.

## 호환 범위

Obsidian의 전체 복제 또는 플러그인 API 호환 구현은 아닙니다. Sync, Publish, 커뮤니티 플러그인, Bases, 모바일 앱, PDF 주석, 모든 고급 Markdown 문법은 포함하지 않습니다. Canvas의 기존 group/link 항목과 알 수 없는 JSON 필드는 보존하지만 그룹 일괄 이동·웹 임베드 생성은 지원하지 않습니다. 그래프는 존재하는 노트를 표시하며 미생성 링크를 가상 노드로 만들지 않습니다. 큰 보관함의 성능·동시 외부 편집 충돌 병합은 별도 검증이 필요합니다.

브라우저에서 Vite를 열면 localStorage 데모로 동작하며 실제 파일 접근은 데스크톱 앱에서 지원합니다.

## 검증 및 분석

`npm test`로 저장, 경로 격리, 링크 갱신, 휴지통 복원, 파일 감지 등을 검증합니다. `npm run build`로 TypeScript와 프로덕션 번들을 확인합니다. 분석 근거와 한계는 [analysis/OBSERVATIONS.md](analysis/OBSERVATIONS.md), 수동 검증 기록은 [analysis/VALIDATION.md](analysis/VALIDATION.md)에 있습니다.
